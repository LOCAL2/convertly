# Convertly: All-in-one Utility Website

Please build a web application called "Convertly", which is an all-in-one utility website featuring the following tools:

├── Unit Converters
│   ├── Length
│   ├── Weight
│   ├── Temperature
│   ├── Time
│   ├── Speed
│   ├── Area
│   ├── Volume
│   ├── Data
│   └── Pressure
│
├── Number Tools
│   ├── Decimal ↔ Binary
│   ├── Binary ↔ Hex
│   ├── Roman Numerals
│   └── Number System
│
├── Time Tools
│   ├── Seconds → Hours
│   ├── Unix Timestamp
│   ├── Date Difference
│   └── Time Zone
│
├── Developer Tools
│   ├── JSON Formatter
│   ├── Base64
│   ├── URL Encode
│   ├── UUID Generator
│   ├── Hash Generator
│   └── Regex Tester
│
├── Color Tools
│   ├── HEX ↔ RGB
│   ├── RGB ↔ HSL
│   └── Color Converter
│
├── Text Tools
│   ├── Word Counter
│   ├── Case Converter
│   ├── Lorem Ipsum Generator
│   └── Markdown Preview
│
├── Image Tools
│   ├── Image Resizer
│   ├── Format Converter
│   └── Base64 Image Encode
│
├── Network Tools
│   ├── IP Address Info
│   ├── DNS Lookup
│   └── URL Parser
│
├── Finance Tools
│   ├── Currency Converter
│   ├── Loan Calculator
│   └── Salary Calculator
│
└── Calculators
    ├── Percentage
    ├── Discount
    ├── BMI
    ├── Date Calculator
    └── Scientific Calculator
